RESUME BUILDER — DESIGN IDEA & FLOW

CONCEPT: This isn't a generic form wizard. It's "your JREE score, 
turned into a resume." Every step should feel like it's pulling from 
data the student already earned, not asking them to start from zero.

ENTRY SCREEN (choice, not straight into a form):
Two large choice cards, not small buttons — this decision matters.
  Card 1 "Build New Resume" — for freshers with nothing yet. Icon 
    suggests creation/spark. Subtext reassures: "we pre-fill from your 
    JREE profile" — removes blank-page fear.
  Card 2 "Beautify My Resume" — for students who already have one. 
    Icon suggests upload/transform. Subtext: "we parse, improve, and 
    add your JREE badge" — this is the upsell, make it feel premium.
  Cards should feel tappable/hoverable with clear elevation on hover — 
  this is a decision moment, treat it with weight, not like a list item.

STEP FLOW (8 steps) — reframe as a narrative, not a checklist:
  1 Personal · 2 Objective · 3 Education · 4 Skills · 
  5 Projects · 6 Certifications · 7 Template · 8 Preview

PROGRESS BAR: Keep the top progress bar, but make the current step 
label feel alive — show the step NAME transitioning (not just "3 of 8"), 
and let the bar fill with a visible motion, not a static jump, each 
time the student advances.

KEY MOMENT — STEP 1 "Let's Start Building":
This is the emotional hook of the whole flow. Instead of a plain 
info box, make the "Profile loaded from JREE" panel feel like a 
live data pull — a small animated checkmark or pulse as each field 
populates (Name, Email, Stream, JREE Score), like the data is arriving 
in real time, not just sitting there pre-filled. The JREE Score shown 
here should carry visual weight — it's proof this resume is different 
from a normal one.

STEP 2 "Career Objective" — the AI moment:
"Generate with Gemini AI" shouldn't be a plain outlined button sitting 
below an empty textarea. Make this the visual centerpiece of the step: 
larger, with a subtle glow or shimmer state, and when clicked, text 
should appear progressively (typewriter-style) into the textarea rather 
than popping in instantly — this sells "AI is writing this for you" 
as an experience, not just a feature.

STEPS 3–6 (Education, Skills, Projects, Certifications):
Keep these calm and utilitarian — they're data entry, don't over-design 
them. But: the "+ Add Education" / "+ Add Project" / "+ Add Internship" 
empty states (currently plain dashed boxes) should feel more inviting — 
add a small illustrative icon or subtle background tint so an empty 
resume section doesn't feel like an error state, it should feel like 
an invitation. Skills step: since skills are "pre-added from JREE 
profile," show them as removable chips/tags immediately visible and 
editable, not as an empty input waiting to be filled — this reinforces 
that JREE already did work for the student.

STEP 7 "Choose Template":
Elevate this from 3 flat thumbnail boxes into a proper visual choice 
moment. Each template card should show a believable mini-preview of an 
actual resume layout (header + lines representing text blocks), with 
the selected card having a clear elevated/highlighted state. Add a 
one-line personality descriptor under each name so the choice feels 
guided ("Classic — safest for ATS", "Modern — stands out visually", 
"Premium — best with strong portfolio").

STEP 8 "Preview" — the payoff screen:
This is the reveal moment — treat it like unveiling the finished 
product, not just another form step. The "AI improvement tips" box 
should feel like a coach's feedback, not a warning banner — reframe 
it as constructive, editorial advice with a friendlier visual treatment 
than a flat highlighted box. The resume preview itself should look 
like an actual physical resume artifact — subtle page shadow/border 
that reads as "this is a real document," not a plain white div. 
Sticky action bar at the top (Back / Preview / Download) is good — 
keep it persistent, but make "Download PDF" the clear visual hero 
action of this entire flow — it's the finish line.

GLOBAL FLOW DETAILS:
— "Save Draft" persists quietly top-right across every step — should 
  feel reassuring/ambient, never demand attention.
— Back/Next button pairing: Back stays low-emphasis (outline/ghost), 
  Next/forward action always the visually dominant button — the whole 
  flow should have a constant, unmistakable sense of forward momentum.
— Step transitions (moving from one step to next) should slide/fade 
  rather than hard-cut — reinforces this is one continuous journey, 
  not 8 separate pages.
— Chat bubble (bottom-right) persists as ambient help across all 
  steps — should feel like a quiet assistant is present, not a support 
  ticket icon.
— Whenever JREE-sourced data appears anywhere in this flow (profile 
  info, skills, score), give it a consistent subtle visual marker 
  (like a small badge or tinted background) so students always know 
  "this came from my exam, I didn't have to type it."

OVERALL FEELING TO ACHIEVE:
The current wireframe feels like a generic SaaS form wizard. The 
redesign should feel like: "JREE already knows me — this resume is 
being assembled from what I've already proven, not built from scratch." 
Every empty state, every AI moment, every pre-filled field should 
reinforce that specific emotional idea.
